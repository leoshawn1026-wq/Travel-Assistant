# WanderWise 🧭 — 产品定位 & 版本迭代清单

> 更新时间：2026-06-07

---

## 🎯 产品定位

**WanderWise = AI 旅行规划助手**
帮助旅行者从"想去哪"到"怎么去"一站搞定，覆盖决策 → 规划 → 执行全链路。

### 四大核心功能

```
┌─────────────────────────────────────────────────────────────┐
│                    WanderWise                                 │
│                                                              │
│  ① AI 目的地对比     ② 智能行程定制     ③ 旅行信息聚合       │
│  ───────────────    ──────────────    ────────────────      │
│  输入人数/预算/       AI 生成按天        行程页内直接查      │
│  动机，AI 从气候/    排布的完整行程，      酒店/餐厅/天气      │
│  费用/体验/签证      支持拖拽调整/        /机票/火车票，      │
│  等维度打分排序       局部重生/导出       信息不出页面        │
│                                                              │
│              ④ 旅行社区                                       │
│              ─────────                                       │
│              发现真实行程 → 一键复制为我的方案                  │
│              点赞/收藏/评论/好友系统                            │
│              旅伴匹配（即将上线）                               │
│                                                              │
│  后续：四个分支各自垂直深耕                                      │
└─────────────────────────────────────────────────────────────┘
```

### 迭代原则
- **功能驱动**：每个版本围绕一个核心功能深耕，不做大而全
- **先验证后投入**：模拟数据先跑通流程，再对接真实 API
- **体验优先**：信息不出页面、流式实时反馈、移动端适配
